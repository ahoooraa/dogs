راهنمای اجرای Dog AI

۱) Node.js را از سایت رسمی https://nodejs.org نصب کن.
۲) این پوشه را از فایل ZIP بیرون بیاور.
۳) در این پوشه، فایل .env.example را کپی کن و نام کپی را دقیقاً .env بگذار.
۴) فایل .env را باز کن و به‌جای put_your_api_key_here کلید API خودت را وارد کن.
   کلید را با کسی به اشتراک نگذار و آن را داخل HTML ننویس.
۵) ترمینال/Command Prompt را در همین پوشه باز کن و اجرا کن:
   npm install
   npm start
۶) در مرورگر باز کن:
   http://localhost:3000

اگر خطای API گرفتی، بررسی کن که API key درست باشد، دسترسی و اعتبار API فعال باشد و نام مدل در صورت نیاز با مدل‌های موجود در حساب تو مطابقت داشته باشد. استفاده از API ممکن است هزینه جداگانه داشته باشد.

برای انتشار عمومی در اینترنت، سرور باید روی یک سرویس میزبانی امن مستقر شود؛ فایل .env را آپلود عمومی نکن.
